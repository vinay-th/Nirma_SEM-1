How it works

Short codes for common characters, long codes for rare ones, and no code ever starts another.

Merge the lightest

The two lowest-weight nodes become siblings under a parent that carries their combined weight.

Label the edges

Left branches read 0 and right branches read 1, so every leaf ends up with a unique path.

Prefix-free codes

Characters live only on leaves, so decoding needs no separators between codes.

Fast to build

A priority queue builds the tree in O(n log n) for n distinct characters, and the result is optimal.
